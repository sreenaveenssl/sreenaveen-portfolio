# Sreenaveen S S L — AI & Digital Technology Portfolio

A responsive, static portfolio website built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local development server, open this folder in VS Code and run:
   `python -m http.server 8000`
4. Visit `http://localhost:8000`.

## Publish it and get a permanent resume URL

### GitHub Pages (free)
1. Sign in to GitHub and create a new **public** repository named `sreenaveen-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/sreenaveen-portfolio/`
6. Open the published URL in an incognito/private browser window and test every section and link.
7. Add that exact URL to your resume under **Portfolio**.

## Before publishing
- Add your actual LinkedIn and GitHub profile URLs.
- Add your resume PDF as `resume.pdf` and add a download link if desired.
- Add project GitHub repository/demo links and screenshots only after verifying them.
- Confirm research-paper titles, journal names, publication links and dates.
- The current portfolio intentionally labels research and projects by the status described in the supplied material.
- Update the phone number and any additional contact information only if you want them public.

## About the “AI” design
The website has an AI-inspired visual style, animated particle network and interactive project filters. These are front-end visual interactions; the site does not call a generative AI API or collect visitor data.
